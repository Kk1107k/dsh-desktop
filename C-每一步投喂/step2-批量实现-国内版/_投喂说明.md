## ✅ 推荐：直接用合并投喂包

**`投喂包-禁网版.txt`**（40KB）= 硬性约束 + prompt-B + 完整 SPEC.md。
整段全选粘贴即可，不用再来回切文件。

约束块做了这些限制（照抄自 step1 的教训）：
禁联网 / 禁工具与技能 / 禁子代理 / 不落盘不跑命令只按 `=== FILE ===` 输出 /
不要开场白 / 信息不足写占位 / 目录树严格照 SPEC / 不动两个生成页面。

## 或者手动粘（按顺序）

1. `prompt-B-国内版-批量实现.md`（本目录，prompt 正文）
2. **`../../B-AI共享/SPEC.md`（完整，粘在 prompt 的"附：SPEC.md"处）**

> ⚠ **一次性粘完，不要分次**。分次会丢失模块间一致性 —— 国产模型最容易踩的坑。
> ⚠ 若手动粘，务必在开头加上禁网约束（直接抄 `投喂包-禁网版.txt` 的第一段）。
