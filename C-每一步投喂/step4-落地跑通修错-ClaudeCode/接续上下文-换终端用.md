## 为什么必须带这份上下文

重开终端后新模型是"失忆"的，最常见的翻车是：

1. **把已修好的缺陷改回去**（比如又把 NSIS 键写成 `...Location`、又把 `require` 塞回 ESM）
2. **擅自改接口名** → 页面与 preload 对不上，表现为**静默失效**（不报错，但状态不动、弹窗不出），
   这是本项目最难排查的一类 bug
3. **重新做架构决策**（比如想换 Tauri、改目录结构）→ SPEC 已冻结，改动即返工

## 换模型的判断标准

**不要为了省钱中途换模型**。只在以下情况重开终端：

- 同一处错误连续 **2 轮**没解决
- 已确认是模型能力短板（比如 GLM-5.3 在某个 Electron API 上反复出错）

切到 DeepSeek V4.1 后档位用 **medium**（报错信息明确时不需要深想，这档最省钱）。
