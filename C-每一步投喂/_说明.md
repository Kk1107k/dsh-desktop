# C-每一步投喂 · 按执行顺序排列

每个目录 = **一个执行步骤**，目录里放的是"这一步要投喂的东西"：
prompt 文件 + `_投喂说明.md`（投给谁 / 什么模型 / 开几档思考 / 还要粘什么 / 产出什么 / 怎么验收）。

| 目录 | 投给谁 | 模型 | 思考强度 |
|---|---|---|---|
| `step0-本地准备` | 你自己 | — | — |
| `step1-架构spec-国际版` | 国际版 GPT | GPT-6 系列 | **high（最高档）** |
| `step2-批量实现-国内版` | 国内版 Agent | GLM 5.3 / 5.2（以列表为准） | **medium（关深度思考）** |
| `step3-更新链路初稿-国内版` | 国内版 Agent | GLM 系列 / DeepSeek | **medium** |
| `step4-落地跑通修错-ClaudeCode` | Claude Code | GLM-5.3 → DeepSeek V4.1 | **xhigh → medium** |
| `step5-最终审计-国际版` | 本地执行 | Claude Code + GLM-5.3 / 瓦力 | **xhigh · 0 积分** |
| `step6-文档收尾与发布-国内版` | 国内版 Agent | 任选国产 | **low / 关思考** |

## 通用规则

1. **每一份 prompt 都先带 `../B-AI共享/` 里的文件**，再带本步骤的 prompt
2. **一次性粘完，不要分次** —— 分次会丢失模块间的一致性
3. 每一步产出后立刻 `git commit`，让下一步的 AI 能看到最新状态
4. 详细版执行手册见 `../A-我读的/执行流程-Runbook.md`
